# Personal Academic Website — Sadnan Sajid

This repository contains the source code for my personal academic and research website. It showcases my work in robotics, AI, embedded systems, and my ongoing research as an EEE student at the University of Asia Pacific, Bangladesh.

## Structure

- `index.html` – main entry point (all sections)
- `css/style.css` – all styling
- `js/script.js` – interactivity (mobile nav, scroll effects, LiDAR canvas animation)
- `favicon.png` – site favicon
- `README.md` – this file

## Features

- Fully responsive design
- Mobile hamburger navigation
- Interactive LiDAR point‑cloud animation on the hero section
- Smooth scroll and active navigation highlighting
- Scroll‑reveal animations
- Font Awesome icons for visual enhancements

## Deployment

Simply open `index.html` in a browser, or deploy to any static hosting service (GitHub Pages, Netlify, Vercel, etc.).
